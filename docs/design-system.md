# Sample 01 디자인 기준

이 사이트는 따뜻한 종이색 배경, 청록색 강조, 세리프 큰 제목을 사용하는 포트폴리오입니다. 밝은 테마와 어두운 테마가 같은 텍스트 계층을 공유합니다.

## 수정 위치

- `src/design-tokens.css`: 테마별 색상, 폰트, 크기, 굵기, 행간, 자간의 기준값
- `src/typography.css`: 제목·본문·보조문·버튼 등 역할별 스타일
- `src/index.css`: 전역 배경, 포커스, 선택 색상, 모션 설정
- `src/presentation/components/`: 내용과 레이아웃. 글자 크기나 굵기를 개별 인라인 스타일/Tailwind 숫자 유틸리티로 덮어쓰지 않습니다.

`src/main.jsx`에서 토큰 → 전역/Tailwind → 역할 스타일 순으로 불러옵니다. 고객 내용은 기존처럼 `src/config.js`에서 수정합니다.

## 색상 팔레트

| 용도 / 토큰 | Light | Dark |
| --- | --- | --- |
| 기본 배경 `--color-bg` | `#f7f6f2` | `#171614` |
| 카드/내비게이션 `--color-surface` | `#f9f8f5` | `#1c1b19` |
| 높은 표면 `--color-surface-2` | `#fbfbf9` | `#201f1d` |
| 이미지 빈 영역 `--color-surface-offset` | `#f3f0ec` | `#1d1c1a` |
| 기본 글자 `--color-text` | `#28251d` | `#e3e1dc` |
| 본문/보조 글자 `--color-text-muted` | `#62615c` | `#aaa8a2` |
| 캡션 `--color-text-faint` | `#6d6c66` | `#9b9993` |
| 강조/링크 `--color-primary` | `#01696f` | `#70bac4` |
| 강조 배경 `--color-primary-hl` | `#cedcd8` | `#313b3b` |
| 강조 버튼 글자 `--color-on-primary` | `#ffffff` | `#171614` |
| 카드 경계 `--color-border` | `#d4d1ca` | `#393836` |
| 구분선 `--color-divider` | `#dcd9d5` | `#262523` |

호버·눌림 색상, 모달 배경, 이미지 위 아이콘 색상과 그림자도 토큰 파일에서 관리합니다. 색상으로 위계를 낮출 때는 불투명도를 낮추지 말고 보조문 토큰을 사용합니다. 본문/보조문/캡션/강조 글자를 네 가지 페이지 표면에, 강조 글자를 강조 배경에, 버튼 글자를 강조색에 조합했을 때 계산한 최소 대비는 Light 4.57:1, Dark 5.23:1입니다. 경계선은 텍스트 대비 계산에 포함되지 않습니다.

## 글자 계층

기본 브라우저 크기 16px 기준입니다. 본문과 작은 글자는 화면 폭에 따라 축소하지 않습니다.

| 역할 / 클래스 | 크기 | 굵기 | 행간 | 용도 |
| --- | --- | --- | --- | --- |
| `type-hero` | 48–88px 유동 | 400 | 1.15 | 페이지의 유일한 `h1` |
| `type-section` | 28–48px 유동 | 400 | 1.3 | 모든 섹션의 `h2` |
| `type-title` | 20px | 700 | 1.45 | 회사·프로젝트·스킬 그룹·자기소개 항목 제목 |
| `type-lead` | 20px | 500 | 1.45 | Hero 직함 |
| `type-body` | 16px | 400 | 1.8 | 소개·경력 성과·자기소개·프로젝트 상세 본문 |
| `type-supporting` | 14px | 400 | 1.65 | 직책과 보조 소개 |
| `type-caption` | 13px | 400 | 1.65 | 기간·기술 태그·상태·통계 설명 |
| `type-eyebrow` | 12px | 700 | 1.65 | 섹션 제목 위 영문 분류 |
| `type-control` | 14px | 500 | 1.5 | 링크 버튼·내비게이션·테마 전환 |
| `type-metric` / `type-metric-compact` | 32px / 24px | 400 | 1.3 | 본문 통계 / Hero 보조 통계 |
| `type-brand` | 20px | 400 | 1.3 | 내비게이션 이름·프로필 이니셜 |

- 큰 제목·브랜드·통계는 Instrument Serif를 사용합니다. 한국어는 명시한 시스템 한글 폰트로 대체됩니다.
- 항목 제목과 본문은 Satoshi 기반 산세리프입니다. 항목 제목은 모든 섹션에서 같은 크기·굵기를 사용합니다.
- 굵기는 실제 사용하는 400 / 500 / 700으로 제한합니다. `type-label`은 작은 라벨에 500을 적용합니다.
- `type-mono`는 기간·순번·수치 태그에만 사용합니다.
- 큰 제목과 항목 제목 자간은 `-0.025em`, 기본 본문은 `-0.01em`, 영문 분류는 `0.12em`, 버튼/고정폭 글자는 `0`입니다.
- 입력 필드가 추가되면 기본 16px를 유지합니다. 한국어 단어를 우선 보존하고 긴 주소·기술 이름은 컨테이너 폭 안에서 줄바꿈합니다.

## 적용 예시

```jsx
<p className="type-eyebrow mb-3">Projects</p>
<h2 className="type-section mb-12">프로젝트</h2>
<h3 className="type-title">프로젝트명</h3>
<p className="type-body">프로젝트 설명</p>
<span className="type-caption">기술 태그</span>
```

모든 페이지 섹션은 `h2`, 그 안의 회사·카드·스킬 그룹·자기소개 항목은 `h3`로 구분합니다. 프로젝트 모달에도 카드와 같은 제목/본문 역할을 사용합니다. 여백, 그리드, 정렬은 기존 Tailwind 레이아웃 클래스로 조절합니다.

## 변경 후 확인

1. `npm run build`로 배포 빌드가 생성되는지 확인합니다.
2. 320px 모바일, 768px 태블릿, 1440px 데스크톱에서 긴 제목·이메일·카드가 잘리지 않는지 확인합니다.
3. Light / Dark 모드에서 본문·메뉴·버튼 글자 대비와 모달의 상세 본문을 확인합니다.
4. 섹션 제목은 동일한 역할, 항목 제목은 동일한 역할을 유지합니다. 모바일 고정 메뉴로 이동해도 제목이 가려지지 않아야 합니다.

저장소의 기존 `lint` 스크립트는 ESLint 의존성과 설정을 제공하지 않습니다. 이 변경은 Vite 프로덕션 빌드와 색상 대비 계산으로 검증합니다.
